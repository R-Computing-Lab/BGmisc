# Recycle a logical flag to a required length (internal)

Recycle a logical flag to a required length (internal)

## Usage

``` r
.recycleFlag(x, n, arg_name)
```

## Arguments

- x:

  A logical vector of length 1 or `n`.

- n:

  Required length.

- arg_name:

  Name of the calling argument, used in error messages.

## Value

A logical vector of length `n`.
